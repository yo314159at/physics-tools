How does a square wave differ from a sawtooth Fourier sum?

Show the answer

They use different harmonic coefficients and phase relationships.

  • Each harmonic is a sinusoid.
  • Amplitude controls the harmonic's size.
  • Adding odd harmonics can approximate a square wave.
Common mistake. A finite Fourier sum never perfectly equals a discontinuous square wave everywhere.
$$f(x)=\sum_{n=1}^{N}A_n\sin(nkx)$$
  1. Set odd harmonics 1, 1/3, 1/5.
  2. Hide the even harmonics.
  3. Increase the number of terms.
