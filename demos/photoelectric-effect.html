Does increasing light intensity eject electrons with more kinetic energy?

Show the answer

Not for the ideal photoelectric effect. Intensity changes electron count, while frequency changes maximum kinetic energy.

  • No emission occurs below threshold frequency.
  • Maximum kinetic energy is linear in frequency.
  • Intensity controls the number of photons and emitted electrons.
Common mistake. Brighter light is not necessarily higher-frequency light.
$$hf=\phi+K_\max,\qquad K_\max=eV_s,\qquad f=c/λ$$
  1. Set wavelength below 400 nm for a sodium-like surface.
  2. Double intensity and compare current.
  3. Change wavelength and read stopping voltage.
